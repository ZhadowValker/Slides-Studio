Publish this deck on GitHub Pages

Your deck lives in your browser until you save it. To share it as a link:

  1. Choose Save deck (.json) from the download menu. The file is named deck.json.
  2. Commit index.html and deck.json to the same repository.
  3. In the repository, open Settings → Pages and set Source to GitHub Actions. The included workflow then publishes every push to main.
  4. Share the link below. It opens the deck full screen.

Use your own Google keys

Normally you only click Sign in with Google. Use this if the site you are on has no Google Client ID built in. Nothing is sent anywhere except Google, and the app can only see files it creates or that you pick.

  1. In Google Cloud Console, create a project and enable the Google Drive API and the Google Picker API.
  2. Under APIs & Services → OAuth consent screen, set up the app and add yourself as a test user.
  3. Under Credentials, create an OAuth client ID of type Web application. Add the address below to Authorized JavaScript origins.
  4. Optional: create an API key restricted to the Picker API. It lets you choose images from anywhere in Drive.
  5. Paste the values here.
